# 研发交付路由

使用公共执行规则，按目标选择连接器。以下领域规则已经在 TAPD 适配模块实现，其他连接器未声明能力时只提供草案并列 gap。

| 用户意图 | 加载 TAPD 适配说明 |
|---|---|
| 需求 intake、验收/原型读取 | ../tapd/intake-gate.md 与 ../tapd/spec-authority.md |
| 编码前审核 | ../tapd/pre-dev-review.md |
| 拆任务 | ../tapd/work-item-orchestrator.md 与 ../tapd/task-orchestrator.md |
| 估时排期 | ../tapd/effort-scheduler.md |
| 计划与开发 | ../tapd/impl-planner.md 与 ../tapd/development-executor.md |
| 用例 | ../tapd/tcase-orchestrator.md |
| 评论同步 | ../tapd/sync-code-comment-to-tapd.md |
| 收尾与工时 | ../tapd/development-finish.md |
| 日报、今日待办、团队盘点 | ../tapd/daily-brief.md |
| 产品规格发布 | ../tapd/spec-publisher.md |
| 产品评审 | ../tapd/product-review-gate.md 与 ../tapd/spec-authority.md |

只有正式产品规格开发要求规格准入；普通需求创建和论坛处理不强迫初始化产品 Git Repo。已评审精确版本仍是事实源，平台描述只是发布副本。
