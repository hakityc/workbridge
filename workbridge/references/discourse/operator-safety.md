# Discourse 运营与管理员操作

读取可先行，变更一律按“读当前状态 → 对象级 dry-run → 明确确认 → 单次写入 → 精确回读”。不要用写调用探测权限，不自动扩大为批量操作，不因已有 `--allow_writes` 省略业务确认。

| 场景 | 必须额外核对 |
|---|---|
| 审核/用户状态 | reviewable 或用户的最新状态、单个动作、对用户的影响；不批量处置 |
| 群组/标签组/类目 | 当前成员、权限和关联；删除要说明级联影响并用精确 ID 回读 |
| 站点设置 | 单一非敏感设置、当前值和期望值；秘密、批量和结构化设置不处理 |
| Webhook | 目标 URL、事件、传递范围和外部副作用；ping/重投不证明对端已消费 |
| 主题 | 代码来源、允许目录、影响所有访客的风险；第三方代码先独立确认，生产改动优先非生产验证 |
| Data Explorer/工作流 | 查询或执行范围、读写边界、运行副作用；保存与执行分别确认 |
| AI 自定义工具/功能 | 源码、提示词、绑定和测试参数均敏感；测试可能执行代码或请求外部系统，先用最小范围 |

权限或插件能力不足时保留 dry-run，不降级为直接 HTTP/API 调用。429/5xx 使用服务端退避；删除、重投、执行等非幂等操作遇到不确定结果不盲目重放。
